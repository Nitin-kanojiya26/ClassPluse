# Face Recognition Models

The `.dat` model files are required for the Face Recognition system to work, but they are too large to be stored in GitHub. 

You must download the following files and place them in this directory (`ClassPluse/FaceModels/`):

1. **shape_predictor_68_face_landmarks.dat**
   - Download from: [http://dlib.net/files/shape_predictor_68_face_landmarks.dat.bz2](http://dlib.net/files/shape_predictor_68_face_landmarks.dat.bz2)
   - Extract the `.bz2` file.

2. **shape_predictor_5_face_landmarks.dat**
   - Download from: [http://dlib.net/files/shape_predictor_5_face_landmarks.dat.bz2](http://dlib.net/files/shape_predictor_5_face_landmarks.dat.bz2)
   - Extract the `.bz2` file.

3. **dlib_face_recognition_resnet_model_v1.dat**
   - Download from: [http://dlib.net/files/dlib_face_recognition_resnet_model_v1.dat.bz2](http://dlib.net/files/dlib_face_recognition_resnet_model_v1.dat.bz2)
   - Extract the `.bz2` file.

4. **mmod_human_face_detector.dat**
   - Download from: [http://dlib.net/files/mmod_human_face_detector.dat.bz2](http://dlib.net/files/mmod_human_face_detector.dat.bz2)
   - Extract the `.bz2` file.

Once extracted, verify that the 4 `.dat` files are placed directly inside this folder.
